# blecaco
use phone to control Blender camera

## 依赖 / 从 git clone 恢复

`wheels/`、`PIL/`、`pillow.libs/`、`websockets/` 被 `.gitignore` 忽略，克隆后需要恢复。  
具体步骤见 [DEPENDENCIES.md](DEPENDENCIES.md)。

## 发布 zip

如果你拿到的是 `blecaco-0.1.0.zip`，`wheels/`、`websockets/`、`qrcode/` 已经包含在包里，直接安装即可；  
`DEPENDENCIES.md` 是给 git clone、换平台或换 Blender 版本时用的。
